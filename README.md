# Dogs

**Dogs** é uma aplicação web desenvolvida com **Next.js**, baseada no projeto Dogs da [**Origamid**](https://www.origamid.com/). A aplicação permite visualizar, publicar e interagir com fotos de cachorros, além de oferecer recursos de autenticação, comentários, curtidas e estatísticas.

## 🔗 Link para visualizar o projeto

[https://dogs-lucasbargas.vercel.app/](https://dogs-lucasbargas.vercel.app/)

## 📌 Principais recursos do App

- Cadastro e autenticação de usuários;
- Login e logout;
- Visualização de fotos de cachorros;
- Publicação de novas fotos;
- Adição e visualização de comentários;
- Página individual para cada foto;
- Visualização de estatísticas;
- Upload de imagens;
- Gráficos para visualização de dados.

## 🚀 Como executar este projeto

### Pré-requisitos

- Possuir o [Node.js](https://nodejs.org/) instalado;
- Possuir o npm instalado.

### Clone o repositório

```bash
git clone https://github.com/LucasBargas/dogs_next.git
```

#### Entre na pasta

```bash
cd dogs_next
```

#### Instale as dependências

```bash
npm install
```

#### Configure as variáveis de ambiente

```bash
# Crie um arquivo .env.local e passe os valores
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

#### Execute o App

```bash
npm run dev
```
